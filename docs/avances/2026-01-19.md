# Avances del Proyecto CFSI - 19 de Enero 2026

## Resumen del día
Rediseño de la vista de Solicitud/Registrar para hacerla mobile-friendly.

---

## Cambios Realizados

### 1. Layout Principal - Soporte CSS Dinámico
**Archivo:** `app/Views/layouts/main.php`

Se agregó soporte para cargar archivos CSS dinámicamente desde el controlador, similar a como se hace con las librerías JavaScript.

```php
<?php
  if (isset($styles))
  {
    foreach($styles as $style)
    {
?>
<link rel="stylesheet" href="<?=$style["css"]?>">
<?php      
    }
  }
?>
```

---

### 2. Nuevo CSS - Solicitud Registro Mobile-Friendly
**Archivo:** `resources/css/solicitud-registro.css`

Características implementadas:
- **Botones flotantes** al lado derecho de la pantalla
- **Campos de formulario más grandes** (font-size 16px, padding amplio)
- **Diseño responsive** para móviles
- **Secciones organizadas** con títulos visuales
- **Animación pulse** en el botón de guardar
- **Tooltips** en botones flotantes (se ocultan en móvil)

---

### 3. Vista Solicitud/Registro Rediseñada
**Archivo:** `app/Views/solicitud/registro.php`

Estructura nueva:
- **Botones flotantes circulares** (Guardar, Calcular, Verificar, Garantías, Datos Personales, Cancelar)
- **3 secciones organizadas:**
  1. Información de la Solicitud
  2. Datos del Crédito
  3. Fiador y Documentos
- Columnas `col-md-6` para mejor visualización en móvil

---

### 4. Controlador Solicitud
**Archivo:** `app/Controllers/Solicitud.php`

Se agregó el array `$data["styles"]` en la función `registrar()`:

```php
$data["styles"]=array(
    array("css"=>base_url("resources/css/solicitud-registro.css?v=".date("s"))),
);
```

### Estructura del Wizard (8 Pasos)

```
Paso 1: Datos Personales
Paso 2: Contacto
Paso 3: Dirección
Paso 4: Referencias
Paso 5: Negocios
Paso 6: Ingresos y Egresos
Paso 7: Activos y Pasivos
Paso 8: Documentos
```

### URLs del nuevo módulo
- `Persona2` - Listado con 3 vistas (lista, cards, tabla)
- `Persona2/registrar` - Nuevo registro
- `Persona2/registrar/{id}` - Editar persona
- `Persona2/contacto/{id}` - Contactos
- `Persona2/direcciones/{id}` - Direcciones con mapa Leaflet
- `Persona2/referencias/{id}` - Referencias
- `Persona2/negocios/{id}` - Negocios con días laborales
- `Persona2/ingresos/{id}` - Ingresos y egresos
- `Persona2/activos/{id}` - Activos corrientes, no corrientes y pasivos
- `Persona2/documentos/{id}` - Documentos con subida de archivos
- `Persona2/detalle/{id}` - Vista detallada de la persona

## Características Implementadas

### Vista Detalle (`detalle.php`)
- Header con foto, datos y estadísticas
- Tabs: General, Créditos, Negocios, Financiero
- Exportar a PDF con html2pdf.js
- Colores estandarizados con variables CSS
- Tablas con padding adecuado

### Vista Documentos (`documentos.php`)
- Cards con iconos según tipo de archivo (PDF, imagen, Word)
- Indicadores de vencimiento (vencido, próximo a vencer)
- Subida de archivos (PDF, JPG, PNG, DOC, DOCX - máx 5MB)
- Campos: título, no. referencia, fecha vencimiento

### Vista Ingresos (`ingresos.php`)
- Resumen con total ingresos, egresos y balance
- Cálculo de ingresos de negocios
- Modales para agregar ingresos/egresos

### Vista Activos (`activos.php`)
- 3 columnas: Activos corrientes, no corrientes, pasivos
- Cálculo de patrimonio
- Modales para cada tipo

## Notas Técnicas
- El proyecto usa CodeIgniter 3
- Framework CSS: AdminLTE + Bootstrap 4
- Los estilos se cargan dinámicamente desde el controlador
- Mapa interactivo con Leaflet.js
- Exportación PDF con html2pdf.js
- Preferencia de vista guardada en localStorage
